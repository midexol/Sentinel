Formal Security Model & Guardrails

Invariants that cannot be violated

High-frequency trading bots manage hundreds of thousands of dollars in volatile capital. Sentinel's execution guarantees ensure autonomous healing never degrades into runaway gas consumption or unauthorized state modification.

INVARIANT I Math Guardrail

Strict Bounded Gas Clamps

AI recommendations and heuristic suggestions are strictly constrained by immutable mathematical bounds before any transaction is signed.

Floor: minGasBumpPct = 10% (EIP-1559 replacement rule)
Ceiling: maxGasBumpPct = 100% (hard budget defense)
Formula: clampedBump = max(minGas, min(suggestedGas, maxGas))
INVARIANT II Circuit Breaker

Triple-Strike Sliding Window

If 3 interventions occur within a 60-second sliding window, Sentinel immediately halts all automated writes and transitions into a fail-closed freeze state.

Threshold: circuitBreakerThreshold = 3
Sliding Window: circuitBreakerWindowMs = 60,000ms
Action on trip: Emits critical webhook alert & locks down signer.
INVARIANT III Key Isolation

Zero Private Key Leakage

Sentinel supports an out-of-band JSON-RPC proxy interceptor mode. The bot continues to sign with its own HSM or secure enclave. Sentinel never sees raw private keys.

Mode: Proxy Interceptor (Port 8545)
Mechanism: Transparently buffers & inspects eth_sendRawTransaction
Zero custody overhead; drop-in integration into any trading stack.
INVARIANT IV Determinism

Fallback Heuristic Redundancy

AI diagnosis via Claude 3.5 Sonnet is augmented by an offline deterministic rulebook. If an API key is absent or the Anthropic endpoint times out, Sentinel falls back cleanly.

Primary: Claude 3.5 Sonnet / Haiku
Fallback: Rule-based base fee gradient analysis (< 2ms latency)
Zero single points of failure in the diagnostic path.
